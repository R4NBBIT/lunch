# 🍽️ 점메추

동료들과 함께 쓰는 점심 메뉴·맛집 뽑기 페이지입니다.

👉 https://r4nbbit.github.io/lunch/

---

## ✨ 기능

### 메뉴 추천
- 메뉴판에서 점심 메뉴를 랜덤으로 뽑아요. 다시 뽑으면 방금 나온 메뉴는 피해요.
- **로그인 안 함**: 기본 메뉴판으로 뽑기·복사만 할 수 있어요.
- **구글 로그인**: 나만의 메뉴판이 생겨요.
  - 추가한 메뉴는 나에게만 보여요.
  - 기본 메뉴를 지우면 나에게만 감춰지고, 다른 사람에게는 그대로 보여요. 지운 기본 메뉴를 다시 추가하면 되살아나요.
  - **내 메뉴판 초기화**로 기본 메뉴판으로 되돌릴 수 있어요.

### 맛집 추천
- 회사 근처 맛집 중 한 곳을 뽑고, 종류·거리·주소와 카카오맵 링크를 함께 보여줘요.
- **비밀번호**를 입력한 사람만 쓸 수 있어요. 로그인은 필요 없고, 한 번 맞히면 그 기기·브라우저에서는 다시 묻지 않아요.
- 휴무일인 가게는 그날 추천에서 자동으로 빠져요.
- **가게 검색해서 추가**: 가게 이름으로 검색하면 회사 근처 후보가 가까운 순으로 나오고, 고르면 종류·주소·거리·카카오맵 링크가 자동으로 채워져요.
  - 카카오맵에서 찾을 수 있고, 경기도 성남시 수정구 **창곡동**에 있는 가게만 추가할 수 있어요.
- 맛집 목록은 비밀번호를 아는 사람들이 함께 고쳐요. 누가 고치면 바로 반영돼요.
- **관리자 기능** (관리자 구글 계정에게만 보여요): 맛집 초기화, 지금 목록을 기본 목록으로 저장, 기본 목록 파일 등록

### 공통
- **복사**: 뽑은 결과를 복사해서 단톡방에 바로 붙여넣을 수 있어요.

## 📂 구조

```
lunch/
├─ index.html        # 페이지 전체 (화면, 기본 메뉴판, Firebase·카카오 연결)
├─ firestore.rules   # Firestore 보안 규칙 (콘솔에 붙여넣는 용도)
└─ README.md
```

- 기본 메뉴판은 `index.html` 안의 `DEFAULT_MENUS`에 있어요.
- 맛집 목록은 코드에 없고 Firestore에만 저장돼요.

### Firestore 데이터

| 경로 | 내용 | 접근 |
|---|---|---|
| `users/{계정ID}` | 내 메뉴판: `added`(추가한 메뉴), `hidden`(숨긴 기본 메뉴) | 구글 로그인한 본인 |
| `members/{계정ID}` | 맛집 비밀번호를 맞힌 기록 | 본인 (등록만) |
| `places/current` | 지금 맛집 목록 | 비밀번호를 맞힌 사람, 관리자 |
| `places/default` | 기본 맛집 목록 (초기화용) | 관리자 |
| `secret/config` | `password`: 맛집 비밀번호 | 아무도 못 읽음 (보안 규칙만 참조) |
| `secret/admins` | `emails`: 관리자 구글 계정 이메일 목록 | 아무도 못 읽음 (보안 규칙만 참조) |

> 비밀번호와 관리자 이메일은 코드에 넣지 않고 Firestore 콘솔에서 직접 관리해요. 비밀번호를 바꾸면 모든 사람이 다시 입력해야 해요.

## 🔧 설정 방법

### 1. Firebase

1. Firebase 콘솔에서 프로젝트를 만들고 **Firestore Database**를 생성해요. (위치: `asia-northeast3`, 프로덕션 모드)
2. **Authentication → 로그인 방법**에서 **Google**과 **익명**을 사용 설정해요.
3. **Authentication → 설정 → 승인된 도메인**에 `r4nbbit.github.io`를 추가해요.
4. **Firestore → 데이터**에서 문서 두 개를 만들어요.
   - `secret/config`: 필드 `password` (문자열)
   - `secret/admins`: 필드 `emails` (배열, 관리자 구글 계정 이메일)
5. **Firestore → 규칙** 탭에 `firestore.rules` 내용을 붙여넣고 **게시**해요.
6. 웹 앱을 등록하고 나온 `firebaseConfig` 값을 `index.html`의 `firebaseConfig`에 넣어요.
7. 관리자 계정으로 로그인한 뒤 맛집 탭에서 기본 맛집 목록 파일(JSON)을 등록해요.

> `firebaseConfig`는 웹페이지에 공개로 들어가는 값이라 저장소에 올라가도 괜찮아요. 데이터 접근은 보안 규칙이 막아줘요.

### 2. 카카오 지도 (가게 검색)

1. 카카오 개발자 사이트에서 앱을 만들고 **앱 → 플랫폼 키 → JavaScript 키**를 확인해요.
2. 같은 곳의 **JavaScript SDK 도메인**에 `https://r4nbbit.github.io`를 등록해요.
3. **제품 설정 → 카카오맵**에서 사용 설정을 켜요.
4. `index.html`의 카카오 SDK 주소(`appkey=`)에 JavaScript 키를 넣어요. 거리 기준이 되는 회사 주소는 `OFFICE_ADDR`에 있어요.

### 3. GitHub Pages

저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 저장하면 몇 분 뒤 위 주소로 열려요.

## ⚠️ 참고

- 비밀번호는 너무 쉬운 걸로 하지 마세요. 페이지에서 여러 번 시도하는 것까지 막지는 못해요.
- 무료(Spark) 요금제라 사용량 한도를 넘어도 요금은 나가지 않고, 그날만 잠시 저장이 멈춰요.
